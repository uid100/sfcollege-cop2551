This is a shortened 13-week course in Object-Oriented Programming (OOP) using C#.  We have a lot of material to cover but it is designed to build on the knowledge and experience you already have. We will start with some assumptions, that you are comfortable with your computer environment and the terminology and are not brand new to programming, but there will be new topics as well. We will be reinforcing common patterns and strategies, some will be new, and as with every new language, the way to succeed and even enjoy  the experience is to immerse yourself in it.

So what can you expect?

There are 13 weeks in the term. We're going to work through part of John Sharp's book: Microsoft Visual C# Step by Step (10th ed)

 

If you don't already have it, find it quick. If you got a great deal on an older edition, you may be ok for at least a few weeks.

 

We're going to be using Microsoft Visual Studio. The current release is '2022.' The Community Edition is a free download. It will take some time and not an insignificant amount of storage space on your computer, but it is the industry standard and you will need this to be successful.  I have a current release, and will be installing any updates this weekend. We're not working on legacy code, so there's no reason not to use the latest and find any sticking points as we go along. (Real-world stuff!). 

 

I'm excited to be teaching and writing code in C# this semester. I routinely code in many different programming languages, but C# is one of my true favorites. Maybe more about that later!

 

Most of the content in this course is new for this semester. If you see something that needs fixing, please let me know right away and I'll get it fixed ASAP!

 

One of the things that is significant, is cross-platform support. dotnet is supported on different platforms. As much as possible, I will be testing the examples and assignments on both Windows and macOS! I'm excited for this goal this semester. Lots of work and lots coding to do! (Yay! Coding is fun!)

 

Mostly, we'll be writing a lot of code. Set aside some time. Write out the examples in the book as you are reading. The time will be well spent. Related to that, some of the sample code is available as a download from the publisher. In general, I firmly believe that you'll get more out of typing the examples yourself than you ever will simply reviewing pre-written code. You won't learn to play the guitar by listening alone, you need to have your fingers on the strings. In much the same way, there are keyboard shortcuts that you pick up along the way, but experience requires trying things and making mistakes.

 

"Online" - The college lists this as a web course. You'll also hear it referred to as asynchronous. We won't have scheduled meetings, but we do have a class schedule to accomplish. The Canvas course is designed to guide you through, but we'll do it together, and I will make an effort to not let you feel alone through the process.
