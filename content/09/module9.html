Inheritance

Class inheritance is one of the (4) fundamental principles of object-oriented programming (OOP). It allows you to create a new class that is based on an existing class, inheriting its properties and methods while also allowing you to extend or modify its behavior.

Inheritance promotes code reusability and can make your code more organized and easier to maintain.

While working through this module, remember the programming principle of Don't Repeat Yourself (DRY). If you find yourself writing the same code multiple times, or tempted to copy and paste code, consider whether inheritance can help you avoid redundancy.
